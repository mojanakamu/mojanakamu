- サイト — https://koggy.dev

## これまで

toC / toB プロダクトの開発を 10 年ほど。Java でのサーバー開発と Android から始めて、UDP を扱う低レイヤーにも手を入れていました。その後は Web のテックリードとして BFF とバックエンド（TypeScript / GraphQL、C# .NET Core の REST API）、直近はネイティブアプリと Web のエンジニアリングマネージャーとして Swift / Objective-C / Kotlin のチームを見ています。
